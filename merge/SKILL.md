# トピックブランチのマージとクリーンアップ

現在のトピックブランチにおける開発を完了し、マージからクリーンアップまでを行います。

## 制約・注意事項
- **`gh` コマンドの認証エラー対策**: エージェント環境で `gh` コマンドを使用する際は、必ず `env -u GITHUB_TOKEN -u GH_TOKEN` をプレフィックスに付けて実行してください。

## 手順
1. **プルリクエスト（PR）の処理**:
   - 関連するPRが存在しない場合は、最後のコミットメッセージや変更内容（`git diff`）から適切なタイトル・説明を考案して新規作成します。
   - PRがDraft状態の場合は `Ready for review` に変更します。
   - 関連するIssueがある場合、紐づいてなかったら紐づける。もしIssue自体が無かったら作る。その際、直近の未クローズのマイルストーンも紐づける。
2. **マージの実行**:
   - PRを **Squash and merge** でマージします（リモートブランチも削除します）。
3. **ローカルのクリーンアップ**:
   - `main` ブランチに切り替えて最新状態（`git pull`）にします。
   - マージしたローカルのトピックブランチを安全に削除します。
     - *※ Squash mergeによるコミットハッシュの不一致で `git branch -d` が警告エラーになった場合は、リモートでマージ完了していることを確認した上で `-D` で強制削除してください。*
